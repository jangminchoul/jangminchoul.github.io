개인정보처리방침

시행일: 2026년 11월 20일 · 운영: 아침7시 (유튜브 채널 '아침7시코인', '아침7시주식')

1. 이 방침이 다루는 것

아침7시는 우리 영상을 우리 유튜브 채널에 올리기 위해 내부 업로드 도구를 씁니다. 이 도구는 채널 주인 한 사람만 쓰며, 다른 사람에게 제공하지 않습니다.

2. 모으는 정보

시청자·방문자의 개인정보는 모으지 않습니다. 이 홈페이지에는 쿠키·방문 추적·광고 도구가 없습니다.

3. 구글 사용자 데이터 (YouTube API)

업로드 도구는 채널 주인이 직접 허락한 구글 계정으로만 아래 일을 합니다.

  • 우리가 만든 영상을 우리 채널에 올리기 (youtube.upload)
  • 연결된 우리 채널 이름·구독자 수·영상 수 확인 (youtube.readonly)
  • 우리 채널의 조회수·클릭률·시청 시간 보기 (yt-analytics.readonly)

로그인 토큰은 채널 주인의 컴퓨터에만 저장되며, 외부 서버로 보내거나 다른 사람과 나누지 않습니다. 구글 사용자 데이터를 팔거나 광고에 쓰지 않습니다. 아침7시의 구글 API 데이터 사용은 Google API Services User Data Policy의 제한된 사용(Limited Use) 요건을 따릅니다. YouTube API 서비스를 쓰므로 YouTube 서비스 약관과 Google 개인정보처리방침도 적용됩니다.

4. 보관과 삭제

토큰은 도구를 쓰는 동안만 보관합니다. 채널 주인은 언제든 구글 계정 → 보안 → 서드파티 앱 액세스에서 권한을 취소할 수 있고, 그러면 토큰은 더 이상 쓸 수 없습니다. 도구를 그만 쓰면 채널 주인의 컴퓨터에 있는 토큰 파일도 지웁니다.
